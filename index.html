About

关于与自检

物理模型
牛顿引力和后牛顿 GR 修正（1PN/2PN/2.5PN 可开关，3.5PN 实验性）以及潮汐相互作用（保守潮 + 时滞耗散 + 自转演化）。速度相关力以逐阶段隐式中点积分，能量误差长期有界；牛顿路径为四阶辛积分，Kahan 补偿求和。
自适应步长由多判据联合控制：最近对动力学时标、每步位移限制与自转演化限制取最小，保证交会与潮汐演化步内解析。
守恒量
能量含 PN 修正、自转能与保守潮汐势；潮汐热与引力波辐射计入账本，核算后 ΔE/ΔL 保持积分器误差级。
渲染
three.js WebGL 渲染：真实网格天体、多星朗伯照明与食阴影、临边昏暗、HDR 自动曝光 + 泛光、全景天空盒；恒星亮度按 质量→半径→温度→光度 物理链计算。加载失败回退极简 2D。
视角 / 参考系
视角跟随、参考系、轨迹参考系三者分离；轨迹按所选参考系重投影，末端与天体当前位置严格对齐。
贴图
等距柱状贴图按自转轴约定映射（图顶 = 北极），全部视图非镜像、北上；双层贴图：底层表面 + 上层 1.5% 外壳差速自转，各有独立不透明度与「暗部透明」云图模式（越黑越透明）。
材质库
自动扫描同目录 textures/ 文件夹（目录列表 → manifest.json → 名称探测），结果本地缓存。星球名.jpg → 底层；星球名_任意 / 星球名-任意 → 该星球上层第二贴图（不覆盖手动设置）；后缀含 cloud/云 等词才自动开启「暗部透明」。file:// 下目录列表受限，推荐本地 HTTP 服务打开。

自转与形变

渲染层效果：自转决定贴图旋转与自转扁化，潮汐椭化按主导伴星方向绘制。流体系数已并入下方结构参数（k2），内部按质量与密度经验自动（土星 0.64 → 地球 0.97 密度锚定，恒星 0.40 太阳扁率锚定）。

潮汐与结构参数（动力学）

单一结构参数：洛夫数 k2（兼作流体性度量）。留空 = 按质量与半径经验公式自动：黑洞 0、中子星 0.195(1−2C)²、恒星 0.056(M/M☉)^−0.65、气巨 0.49+0.44log₁₀(ρ̄/1326)、岩质 0.30+0.1445log₁₀(M/M⊕)（地球 0.300/火星 0.145/月球 0.0243 对标实测）。Δt 留空 = 按类别自动（地球 600 s 复现月退、恒星 Q≈10⁶、气巨 Q≈1.5×10⁴、黑洞 0）。填 0 表示显式关闭。

轨道根数

相对主天体，填写后优先于绝对坐标。角度单位为度，偏心率 0 至 1。
