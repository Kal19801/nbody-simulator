About

关于与自检

物理模型 牛顿引力 + 后牛顿 GR（1PN/1.5PN 自旋 Kidder/2PN/2.5PN，3.5PN 实验性）+ 潮汐（保守潮 + 时滞耗散 + 自转演化）；速度相关力以逐阶段隐式中点积分；积分器 Yoshida 4 阶辛 / IAS15 15 阶 Gauss-Radau（Rein-Spiegel 自适应）；Kahan 补偿求和；自适应步长多判据联合控制。
黑洞渲染 v23 逐像素视线重建 + Python 光线追踪对照（Synge 1966 逃逸锥 / James+2015 CQG 32 065001 近距相机 / Bardeen 1973 临界曲线口径）；影子/偏折同源 b=D·sinθ/√(1−rs/D)；成像距离下限 4.2rs（近距不再吞没全屏，天空环恒可见）；天空盒显式 LOD0 + ρ 平滑上限 2.5π（消除 mip 黑环/散点）+ 全球透镜无接缝 + 影缘 1.5px 软边；Kerr 位移场 LUT 内嵌（a*×incl 网格）+ Bardeen 解析影界。
渲染 three.js WebGL：真实网格天体、多星朗伯照明与食阴影、临边昏暗、HDR 自动曝光 + 泛光、全景天空盒；恒星亮度按 质量→半径→温度→光度 物理链计算；加载失败回退 2D。
视角 / 参考系 视角跟随、参考系、轨迹参考系三者分离；轨迹末端与天体当前位置严格对齐。
贴图 等距柱状贴图按自转轴约定映射（图顶 = 北极），全部视图非镜像；双层贴图各有不透明度与「暗部透明」云图模式。
材质库 自动扫描同目录 textures/（目录列表 → manifest.json → 名称探测，结果本地缓存）。星球名.jpg → 底层；星球名_任意 → 上层第二贴图；后缀含 cloud/云 才自动开启暗部透明。
